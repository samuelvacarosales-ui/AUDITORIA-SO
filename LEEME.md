# Anexo SO — cómo actualizar tu GitHub

Usa el MISMO repositorio que ya tienes. Son 9 archivos, todos sueltos.

1. En tu repositorio: Add file → Upload files.
2. Arrastra los 9 archivos de esta carpeta a la vez
   (index.html, app.js, core.js, sw.js, manifest.json, icon-192.png,
   icon-512.png, xlsx.full.min.js, jspdf.umd.min.js).
   Los que ya existen se sustituyen.
3. Commit changes.
4. Espera 1-2 minutos. En el iPhone abre la app con internet y ciérrala
   del todo; al volver a abrirla ya carga la versión nueva.
   Si sigue viendo la antigua: borra el icono y vuelve a añadirlo desde Safari.

## Flujo de trabajo
1. Descargas el Excel de Repsol y lo rellenas como siempre (SÍ / NO / N/A / PTE).
2. En la app: "Cargar Excel rellenado".
3. Añades fotos (+) donde las necesites; recortas, rotas y eliges tamaño.
4. "Vista previa del informe" → "Guardar PDF".
5. Subes a la plataforma el Excel original y el PDF.
